# Code of Conduct

HyperType is maintained as a respectful, technical collaboration space.
Participants must be considerate, communicate constructively, and keep
discussions focused on the project.

Harassment, discrimination, threats, personal attacks, and publishing private
information are not acceptable. Maintainers may remove content or restrict
participation when these standards are not met.

Report conduct concerns privately to the repository maintainers through GitHub.
Please do not include sensitive security details in a conduct report.
