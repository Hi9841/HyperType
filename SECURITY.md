# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull
requests. Use GitHub's private vulnerability reporting or security advisory
workflow:

https://github.com/Hi9841/HyperType/security/advisories/new

Include the affected version, reproduction steps, impact, and any suggested
mitigation. The maintainers will acknowledge reports as soon as practical.

## Scope

The latest release and the default branch are the supported versions. Older
builds may contain issues that are already fixed.
